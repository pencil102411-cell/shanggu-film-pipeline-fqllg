# 示例项目

这是总调度（`film-pipeline`）开一场戏后，项目文件夹大概的样子。内容是虚构的「示例剧」，只用来看结构，不是真实素材。

```
示例剧/
└─ S01/                    一场一个文件夹，对应一个画布项目「示例剧-S01」
   ├─ 进度表.md            总调度维护：每条视频做到哪了、文件和画布节点在哪
   ├─ 01_分镜/分镜.md       你给的分镜原件（只复制，不改）
   ├─ 03_提示词/第1条_v1.md  提示词 skill 写好、总调度存下来的提示词
   ├─ 04_素材表.md          这场上传到画布的素材（不写编号）
   └─ 04_接线单/第1条_v1.md 第1条 v1 建节点时，(图片1)、(图片2)、(图片3) 各接哪个素材
```

这个例子没做灰模，所以没有 `02_预演/`；也没用局部修改或换机位，所以没有 `05_修改/`。场次记忆要你明确说「建立场次记忆」才会有。
