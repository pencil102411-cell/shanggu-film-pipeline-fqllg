# 第1条 v1（示例，虚构）

<!-- 总调度把提示词 skill 交付的代码块原样存在这里，代码块外的假设和拆点一起存；「本轮读取清单」不存进文件。 -->

```
【素材引用】
人物（按首次出场顺序）：
(图片1) 是角色A；只取面部、发型和本场服装，不取图片背景
(图片2) 是角色B；只取面部、发型和本场服装，不取图片背景
场景：
(图片3) 是庭院廊下的夜景方向；只取空间结构和陈设，不取图中人物和光线

【生成目标】
横屏真人电影写实，古装。夜雨庭院，角色B 来找角色A，两人隔着雨幕对视。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音；只保留台词、动作声和环境声。

【光影设计】
- 主光方位：廊檐下的灯笼在角色A 头顶偏前方
- 光质：灯笼是柔光（soft light），庭院是低照度的夜间散射光
- 光比：廊下明、庭院暗，明暗差明显
- 动机光源：廊檐下的纸灯笼
- 色调：灯笼暖橙与庭院冷蓝对比
- 主体与背景分离：灯笼暖光勾出角色A 的肩部轮廓，和暗蓝的雨幕分开

【时间轴】
0-4s：全景，32mm，摄影机在庭院中轴约 8 米外，廊下和雨幕都在景深内，固定机位。(图片3) 的廊下，角色A 背对镜头站在灯笼下，雨丝斜落，衣摆被风轻轻带起，檐角滴水。结束时：角色A 仍背对镜头，站在廊下正中。
4-7s：切至近景，85mm，摄影机在月门内侧约 3 米，背景雨幕虚化，固定机位。角色B 从月门走进，停步，视线落在角色A 背上，呼吸放缓，肩头的雨水顺着衣襟滑落。结束时：角色B 站在月门内一步，看向廊下。
7-12s：切至中近景，85mm，摄影机在角色A 侧前方约 2.5 米，缓慢前推。角色A 缓缓转身，视线越过雨幕停在角色B 身上，嘴唇先抿住，再开口。角色A台词（平静）：{你还是来了。}结束时：角色A 面向月门，与角色B 对视，灯笼光照在角色A 的半边脸上。

【保持一致】
人物身份、人数、服装、空间方向、光源方向保持一致。
人物为正常人眼，不发光。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音。
```

代码块外的说明（示例）：

- 时长按分镜逐镜相加为 12 秒。镜1–5 合起来 22 秒，本来可以一条做完；按你的要求从镜4起单独做第2条，方便分开返修。
- 这一条要上玄上画布，画布不支持参考音频，所以没接音色参考；台词语气写在（平静）里。
- 灯笼位置是按场景名拟定的工作布光，场景图里看到实际灯具后以图为准。
