# Seedance 2.5 平台说明（共用）

本插件所有 skill 共用的平台事实：能力和上限、任务类型、写实人脸素材、声音、官方已知问题、各入口差异。各 skill 自己的写法和经验留在各自文件里：生成提示词的五区块和写法在 `horizontal-cinematic-prompt-agent-v2`，编辑参数和实测记录在 `video-local-edit` 的 `references/platform-notes.md`，灰模视频的要求在 `blender-greybox-previs` 的 `references/Seedance交付规范.md`，Scenario 作者案例在 `video-rephotography` 的 `references/platform-notes.md`，深度视频的转法和交接卡在 `video-depth-rerender`。素材引用怎么写见同目录的 `素材引用写法.md`。

**核对日期与来源**：火山方舟部分核对于 2026-10-09；玄上画布部分按画布工具 0.4.2 的规则整理（2026-10-21）。平台限额会变，提交前以当前入口为准；用户提供的实际平台限制或已验证的能力优先。

## 一、能力和上限

| 项目 | 数值 | 来源 |
|---|---|---|
| 每条生成时长 | 4–30 秒。玄上画布可选 4–30，或 -1（自动） | 官方；画布工具 |
| 画幅 | 21:9、16:9、4:3、1:1、3:4、9:16、自适应 | 画布工具 |
| 21:9 输出尺寸 | 1470×630（灰模默认用这个尺寸） | 第三方整理 |
| 编辑任务输出尺寸 | 跟着母版（某入口实测一次：母版 992×432，输出也是 992×432） | `video-local-edit` 实测 |
| 素材总数 | 最多 50 个：图片 30 张、视频 10 段、音频 10 段 | 官方 |
| 视频总时长 | 一次生成里所有视频加起来不超过 30 秒（待编辑视频也算在内，所以它越长，能附带的参考视频越短） | 官方 |
| 音频总时长 | 不超过 30 秒 | 官方 |
| 单段视频时长 | **最短按 4 秒算**，最长 30 秒，参考视频和待编辑视频都一样。官方明确的是待编辑视频 4–30 秒；「参考视频最短 2 秒」只见于第三方整理，未核实，本插件按 4 秒处理（2026-10-21 用户决定）。不够 4 秒的参考视频：剪的时候前后多留一点（手柄，即前后多留的余量），或连上相邻镜头凑够 4 秒，提示词里写明只参考哪一段 | 官方；用户决定 |
| 视频文件 | mp4 / mov；视频编码 H.264 / H.265；音频 AAC / MP3（mov 还支持 PCM）；帧率 24–60；单个不超过 200 MB；宽高比 0.4–2.5；边长 300–6000 px；总像素 407,696–8,295,044 | 官方（编辑任务的输入视频要求） |
| 推荐数量 | 人物 1–8 个时最稳定；编辑任务的参考图 1–5 张效果较好，6–8 张可以试。50 是上限，不是目标 | 官方 |
| 参考图分辨率 | **本插件默认照原图分辨率上传，不先缩小**（2026-10-21 用户决定）。官方建议是不要超过输出分辨率，否则草地、树叶等密集纹理处可能出现指纹状纹理，本插件不默认照做 | 用户决定；官方 |
| 分辨率 | 样片 480p；正式 480p / 720p / 1080p（API 默认 720p；1080p 输出为 10bit H.265） | 官方 |
| 样片转成片 | 先出 480p 样片，确认后用样片任务生成 1080p 成片，两步分别计费。玄上画布：只有 Seedance 2.5 的样片能转，样片超过 7 天就不能转 | 官方；画布工具 |
| 保存期限 | 火山方舟输出视频链接保存 24 小时、最多下载 100 次；任务记录保存 7 天。生成后及时下载 | 官方 |

一致性：用实际可用的参考素材、明确的身份和连续性描述提高一致性；不承诺每次生成都能准确执行。

## 二、任务类型和第一句怎么写

| 任务 | 第一句 | 要用的词 | 不能出现的词 |
|---|---|---|---|
| 参考生视频（默认） | 不写任务类型 | — | 修改、替换、增加、删除、延长、延续、续写。即使带参考视频也不用，改用「保持」「承接」，以免被判成编辑或延长 |
| 视频编辑 | 「编辑(视频1)……」，写清改哪个视频、改哪段时间、改什么、保留什么 | 编辑视频、增加/加上、删除/去掉、修改/替换/改成 | 向前/向后延长、延续、续写（以免被判成延长） |
| 视频延长 | 写明向前或向后延长哪个视频 | 向前/向后延长、延续、续写 | — |
| 首尾帧（含只给首帧） | 只给首帧：「以(图片1)作为首帧」；首尾帧：「以(图片1)作为首帧、(图片2)作为尾帧」（2026-11-11 用户决定，仿照关键帧的写法；官方具体句式未核实） | — | — |
| 关键帧 | 「以(图片1)、(图片2)、(图片3)的顺序作为关键帧」，逐张写出，不写「至」 | — | — |

「第一句」放在哪：视频编辑的提示词直接以「编辑(视频1)……」开头（见 `video-local-edit`）；五区块的生成提示词里，延长、首帧、首尾帧、关键帧这一句放在【素材引用】的第一行（2026-11-11 用户决定，见 `horizontal-cinematic-prompt-agent-v2` 的 `templates/标准输出模板.md`）。

玄上画布建节点时，模式要和任务对上：参考生视频用「多模态参考」，首帧用「首帧生视频」（只能接 1 张图），首尾帧用「首尾帧生视频」（只能接 2 张图），编辑用「视频编辑」（时长只能跟着原视频），延长用「视频延长」。Seedance 2.5 除「多模态参考」外，其余四种模式比例都只能选「自适应」，所以首帧、首尾帧的图本身就要做成目标画幅。

火山方舟 API 怎么判定任务类型、编辑任务的参数和报错，见 `video-local-edit` 的 `references/platform-notes.md`。

## 三、写实真人脸素材

按入口分开看：

- **火山方舟 API**：官方说明 Seedance 2.5 不支持直接上传含真人人脸的参考图或视频。例外：用你自己火山方舟账号里、部分模型生成出来且没改动过的原始文件（即使带真人脸）可以作为输入，不会触发审核拦截。经过裁剪、拼接、转码的文件是否仍算原始文件，未核实，先用小样测试。
- **玄上画布**：素材走「认证」流程上传。写实人脸能不能通过认证还没实测；认证失败时，把画布的原始报错告诉用户。
- **实测（2026-10-09，某入口，入口名未记录）**：写实人脸三视图能上传、没被拦截，但正脸特写的长相没有换成。
- 不做「所有入口一律禁止」的判断（2026-10-21 用户决定按入口分开写）。

## 四、声音

- **符号**：音乐用 `()`，音效用 `<>`，台词用 `{}`，字幕用 `【】`。音乐的圆括号别写成「图片/视频/音频 + 数字」的样子，以免被当成素材编号（见 `素材引用写法.md`）。
- **台词**：写成「角色台词（语气）：{台词原文}」，台词后面不再复述词语、语气或动作，以免诱发字幕。
- **去背景音乐**：把音乐类同义词列全（音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音），开头和结尾各写一次。
- **音轨**：编辑任务输出的音轨曾是 AAC 32kHz（母版是 44.1kHz），需要原音时换回原音轨（2026-10-09，某入口 9 条编辑输出的观察，不是官方规则，见 `video-local-edit`）。

## 五、官方已知问题与对策

| 现象 | 对策 | 主要出现在 |
|---|---|---|
| 写了「不要字幕」仍出现字幕 | 母版或参考素材不要带字幕；台词按「角色台词（语气）：{内容}」写，台词后不复述词语 | 生成、编辑 |
| 写了「禁止背景音乐」，特效音仍被做成音乐 | 音乐类同义词列全，开头和结尾各写一次；或后期分离人声（会连同音效一起去掉） | 生成、编辑 |
| 情绪描述过强，瞳孔发光 | 最高优先级约束「正常人眼、不发光」，改用平和的情绪词 | 生成、编辑 |
| 参考图引发指纹状纹理 | 官方对策是参考图分辨率不超过输出分辨率；本插件默认照原图上传，不预先缩小（用户决定） | 生成、编辑 |
| 音频出现水泡声、回音、啸叫 | 去掉提示词中与水、波浪、回音有关的描述 | 生成、编辑 |
| 一次承担多项参考和编辑要求，效果不稳定 | 拆成多个简单任务，例如先用参考任务生成某个动画，再在编辑任务里引用它 | 生成、编辑 |
| 编辑输出比原片短约 0.33 秒 | 输入帧数调成 8n+1；或用 Seedance 2.5 自己的产物作输入；或改用参考生成（内容不再严格一致）。实测也出现过变长，见 `video-local-edit` | 编辑 |
| 用编辑改画幅，补出来的画面和时序不一致 | 改用参考生成，并逐镜描述时序与画面内容 | 编辑 |
| Seedance 2.0 与 2.5 美学风格差异大 | 官方针对延长任务建议用 mov 保持 2.0 风格；编辑 2.0 产物时同样检查风格漂移（这一条是推断，未经官方验证） | 延长、编辑 |
| 特殊色度采样的 JPG 解码失败 | `ffmpeg -i in.jpg -pix_fmt yuvj420p fixed.jpg`，或转成 PNG | 上传素材 |

## 六、各入口差异

| 入口 | 引用写法 | 要点 |
|---|---|---|
| 玄上无限画布（本插件主用） | `(图片1)`、`(视频1)`，第一版不支持参考音频 | 通过 `xuanshang-canvas` 操作。默认参数：Seedance 2.5、多模态参考、样片、21:9、种子 1、mp4、5 秒；用户没说时按这一条的实际情况传时长和模式 |
| 火山方舟 API | `@图片1`、`@视频1`、`@音频1` | 模型 ID `doubao-seedance-2-5-260628`；视频只能通过公网链接或素材 ID 传入；编辑参数见 `video-local-edit` 的 `references/platform-notes.md` |
| Runware（英文） | `@Video1`、`@Image1` | 源视频放 `inputs.video`；`duration` 必须是 `"auto"`（整数会被拒）；画幅继承源视频，不接受 `width`、`height`；可附 `inputs.referenceImages`、`inputs.referenceAudios`；提示词以 remove、replace、relight、restyle、change to 等编辑动词开头；建议输出 MOV，尤其是链式编辑 |
| Scenario（英文） | `@video1` | 知识库（2026-09-23）：编辑用视频参考与 Auto 时长，画幅继承源视频，提示词上限 6,000 字符；作者案例页写 10,000 字符。以当前入口实际能提交的为准 |
| 其他入口 | 先核实 | 是否支持编辑任务、引用写法、时长与画幅行为、音轨行为。只支持图生视频的入口，不能当作等效的视频编辑 |
