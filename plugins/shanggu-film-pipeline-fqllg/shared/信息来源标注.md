# 信息来源标注（共用，原名「证据分级」）

分析视频、建时间表、写母版记录时，**每一个事实都写明是怎么知道的**，不把猜的写成看过的。换机位重拍和局部修改共用这套规则。

## 四类来源

拿「第 3 秒她放下杯子」举例：

| 标注 | 意思 | 例子 |
|---|---|---|
| 实测 | 自己打开视频、逐帧看过或用工具量过 | 用 ffprobe 或抽帧确认就在第 3 秒 |
| 用户提供 | 用户说的，自己没有核对 | 用户告诉你是第 3 秒 |
| 估计 | 根据线索推算 | 按台词长短推算，写「约第 3 秒」 |
| 未知 | 不知道 | 写「待核对」 |

## 规则

- **只有测过的才叫「实测」**。没有看视频、听声音的能力时，不声称看过、听过或逐帧核对过。
- **精度不高于来源**：用户给的小数秒可以原样保留，但注明来源；估算的写「约」；帧对齐带来的舍入误差要说明。严格逐帧验收时，只有实际核对到帧，才说「逐帧一致」。
- **缺的先标「待核对」**，能做的部分照常先做，不为缺一项信息停下。
- **文件存在不等于内容已确认**：文件路径在，不能说明画面是什么；用户描述的结果，不能写成自己看片核验过。
- **改了素材就重来**：裁剪、变速、换文件之后，重新建立时间表，不沿用旧时间码。

## 交付时报告核对到哪一步

分项写「通过 / 有问题 / 未检查」，并写明检查范围。只写了提示词，不等于后面几项通过：

| 项目 | 什么情况下才能报「通过」 |
|---|---|
| 文本规则 | 提示词、变更单或机位表自己前后一致 |
| 原片（母版）时间轴 | 实际量过原视频的帧数、时段和切点 |
| 生成成片 | 实际看过生成结果 |
| 音轨 | 实际对过声音 |

各 skill 的完整验收清单在各自文件里：换机位重拍见 `video-rephotography` 的 `references/timeline-and-qa.md`，局部修改见 `video-local-edit` 的 `references/edit-sheet-and-qa.md`。
