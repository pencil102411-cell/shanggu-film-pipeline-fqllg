# 素材引用写法（共用）

本插件所有 skill 写提示词时，素材引用统一写成玄上画布的格式：**半角括号 `(图片N)`、`(视频N)`、`(音频N)`**（2026-10-21 用户决定）。换到其他入口时整体替换，见文末。

## 基本规则

1. **每一处引用都带括号和编号**，包括正文，不只是开头的素材说明。「背景采用图片3」要写成「背景采用(图片3)」。
2. **不省略、不写范围**。「图片7、8」「(图片7)、8」「图片1—8」「(图片1)至(图片3)」都不行，逐个写成 (图片7)、(图片8)。
3. **关键帧逐张写出**：「以(图片1)、(图片2)、(图片3)的顺序作为关键帧」，不写「至」。
4. **提到参考视频也写编号**：「(视频1)的运镜」，不写「参考视频1的运镜」。
5. **「图片」「视频」后面不要紧跟不是编号的数字**：「参考视频27秒」写成「参考视频时长为27秒」，「图片3张」写成「三张图」。
6. **每条视频各自编号**：图片、视频、音频各自从 1 开始，按这一条接入素材的顺序（玄上画布是建视频节点时给的素材顺序：第一个图片节点就是 (图片1)）。同一个素材在不同条里编号可能不一样，不要把上一条的编号直接搬过来。
7. **编号和接入的素材一一对应**：编号不能超过这一条接入的数量；接入的每个素材都要被引用到，而且只写一个用途。
8. **只用真实编号**：不要发明 (人物1) 这类代号。还没有素材时可以先用「@角色名」「@场景名」占位写提示词，在代码块外注明「需替换为实际素材」；**上玄上画布之前必须换成 (图片N)**：画布不认占位。接了图片却只写占位，画布工具会因为「接入的图片没被引用」拒绝建节点；一张图都没接时不会报错，等于没给参考图。
9. **统一用半角括号**。全角（图片1）、@图片1 画布工具会自动转成半角，但写的时候就写半角。
10. 声音符号里「音乐用圆括号」（见 `Seedance平台.md`「四、声音」）也是圆括号，写音乐时别写成「图片/视频/音频 + 数字」的样子，以免被当成素材编号。

## 玄上画布的额外限制

- **第一版不支持参考音频**：人物音色、环境声改成文字描述；(音频N) 只在支持音频参考的其他入口使用。
- **本地参考视频要先上传认证**才能接入；画布上已经生成好的视频（视频节点、成片节点）可以直接接入当参考。
- 画布工具建节点时会逐处检查引用，有问题会拒绝并指出第几行哪一处；提交生成前还会再查一遍。

## 换到其他入口

| 入口 | 写法 | 怎么换 |
|---|---|---|
| 玄上无限画布（本插件主用） | `(图片1)`、`(视频1)` | 不用换 |
| 火山方舟 API 等写 @ 的中文入口（即梦等其他入口未核实，用前看界面） | `@图片1`、`@视频1`、`@音频1` | (图片N) → @图片N，(视频N) → @视频N，(音频N) → @音频N |
| Runware、BytePlus 等英文入口 | `@Image1`、`@Video1` | 按英文模板写（见 `video-local-edit` 的 `references/edit-prompt-template.md` 文末） |
| Scenario（英文） | `@video1` | 按 `video-rephotography` 的 `references/platform-notes.md` 里的作者案例 |

**怎么换**：跟 AI 说「这条要贴到火山方舟」，它会把整条里的 (图片N)、(视频N)、(音频N) 都换成 @图片N、@视频N、@音频N。自己手动改时，左右括号都要去掉（只把「(图片」换成「@图片」会多留一个「)」）；音乐用的圆括号别动。

换入口前，先在当前界面确认它的引用写法；各入口的其他差异见 `Seedance平台.md`「六、各入口差异」。
