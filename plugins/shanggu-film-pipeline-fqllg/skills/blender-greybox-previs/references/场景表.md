# 场景表 scene.json

## 坐标约定（三张表通用）

- 单位一律是**米**。
- 平面图上**向右 = +X，向上 = +Y**，高度 = Z，地面 Z = 0。
- 原点 (0, 0) 自己定，建议放在房间内墙的左下角。这样房间里的坐标都是正数，好读。
- **角度（朝向、旋转）按罗盘算**：0 = 朝平面图上方（+Y），90 = 朝右（+X），180 = 朝下，270 = 朝左，顺时针增加。

## 整体结构

```json
{
  "name": "帝鸿书房",
  "plan": {"image": "input/平面图.png", "px_per_m": 60, "origin_px": [60, 420]},
  "defaults": {"wall_height": 3.2, "wall_thickness": 0.24},
  "background": "#9a9a9a",
  "ground": {"enabled": true, "margin": 30, "z": 0},
  "ref_person": [4.0, 3.0],
  "check_views": [{"name": "门口看进来", "pos": [2.0, 0.4, 1.6], "look": [4, 4, 1.2], "lens": 20}],
  "elements": [ ... ]
}
```

| 字段 | 必需 | 说明 |
|---|---|---|
| `plan` | 有平面图就写 | 平面图位置和比例，见下一节 |
| `defaults.wall_height` | 否 | 墙默认高度，默认 3.0 |
| `defaults.wall_thickness` | 否 | 墙默认厚度，默认 0.24 |
| `background` | 否 | 背景（天空）颜色，默认中灰 |
| `ground` | 否 | 自动铺一块大地面（可行走）。写 `false` 关掉 |
| `ref_person` | 否 | 1.75 米参照人的位置，只在 `scene` 阶段出现；默认放场景中心；写 `false` 不放 |
| `check_views` | 否 | 自定义检查视角；不写就自动从四个角落看中心 |
| `elements` | 是 | 场景里的东西，见后文 |

## 平面图比例 `plan`

两种写法，二选一：

**① 像素/米 + 原点像素**（图上有清楚的比例时最简单）

```json
"plan": {"image": "input/平面图.png", "px_per_m": 60, "origin_px": [60, 420]}
```

- `px_per_m`：1 米在图上等于多少像素。例：标注 8000mm 的墙在图上长 480 像素，就是 480 ÷ 8 = 60。
- `origin_px`：你定的世界原点 (0, 0) 在图片上的像素位置。图片像素从左上角数起，向下为 y 增大。

**② 两点标定**（知道图上两个点的真实坐标时用）

```json
"plan": {"image": "input/平面图.png",
         "calib": [{"px": [60, 420], "m": [0, 0]}, {"px": [540, 420], "m": [8, 0]}]}
```

默认平面图没有旋转（图片的上方就是 +Y）。如果平面图是歪的，先请用户提供摆正的图，或者自己旋转后另存再用。

写好 `plan` 后运行 `plan-grid`，在 `平面图_米制网格.png` 上读每样东西的坐标。

## 元素类型

每个元素都有 `type`，以及可选的 `name`。**`name` 要唯一**，镜头表里隐藏物体、站位表里 `ignore` 都用这个名字。

通用可选字段：

- `z`：底部高度（放在高台上的家具写台面高度）
- `color`：颜色，默认按类型用不同的灰
- `solid`：是否算实体，实体会挡人走、挡视线
- `walkable`：人能不能站在上面
- `cutaway`：镜头里能不能被"自动剖墙"隐藏。墙、栏杆、天花默认可以

### wall 墙

```json
{"type": "wall", "name": "外墙", "closed": true, "names": ["南墙", "东墙", "北墙", "西墙"],
 "path": [[-0.12, -0.12], [8.12, -0.12], [8.12, 6.12], [-0.12, 6.12]],
 "thickness": 0.24, "height": 3.2,
 "openings": [
   {"kind": "door",   "center": [2.0, -0.12], "width": 1.0, "height": 2.2},
   {"kind": "window", "center": [8.12, 3.0],  "width": 1.5, "height": 1.5, "sill": 0.9}
 ]}
```

- `path` 是墙**中心线**的折线；`closed: true` 表示首尾相连。墙厚向两侧各分一半，所以内墙面在中心线往里 `thickness/2` 处。
- **每一段墙都是单独的物体**，默认叫 `外墙_1`、`外墙_2`……（按 path 顺序，从 1 数）。用 `names` 可以给每段起名，方便镜头里按名字隐藏。
- `openings` 是门窗洞：
  - `center` 写洞中心的平面坐标（会自动找最近的那段墙），或者用 `seg`（段号，从 0 数）加 `at`（从这段起点量到洞中心的距离）。
  - `width` 洞宽；`height` 洞高（门默认 2.1，窗默认 1.5）；`sill` 洞底离地高度（门默认 0，窗默认 0.9）。
  - 洞是空的，不放门板和玻璃。

### railing 栏杆

写法同墙，默认高 1.05、厚 0.06。

### box 长方体（家具、台子、屏风……）

```json
{"type": "box", "name": "书案", "from": [3.1, 4.9], "to": [4.9, 5.5], "h": 0.78, "z": 0.45}
{"type": "box", "name": "屏风", "center": [4.0, 2.0], "size": [1.6, 0.1, 1.8], "rot": 30}
```

- 写法一：`from` / `to` 是两个对角（只能正着放），`h` 是高度。
- 写法二：`center` + `size` [X 方向宽, Y 方向深, 高] + `rot`（顺时针旋转角度，可选）。

### slab / floor 地台、楼板（可以站人）

```json
{"type": "slab", "name": "高台", "polygon": [[2.5, 4.5], [5.5, 4.5], [5.5, 6.0], [2.5, 6.0]], "z": 0.45, "thickness": 0.45}
```

`z` 是**顶面**高度，`thickness` 往下的厚度。二楼楼板就写 `z: 3.0, thickness: 0.2`。

### ceiling 天花板

写法同 slab。俯视图里自动隐藏；镜头里挡住视线时会被自动剖开。不需要拍到天花板时可以不建。

### prism 任意形状的柱体

```json
{"type": "prism", "name": "L形柜台", "polygon": [[0, 0], [3, 0], [3, 0.6], [0.6, 0.6], [0.6, 2], [0, 2]], "h": 1.0}
```

默认是实体、不能站人，适合不规则家具。

### stairs 台阶 / 楼梯（可以站人，人物走上去会自动升高）

```json
{"type": "stairs", "name": "高台台阶", "from": [4.0, 3.6], "to": [4.0, 4.5], "width": 3.0, "height": 0.45, "steps": 3, "z": 0}
```

`from` 是最下一级的前沿中点，`to` 是最上一级的后沿中点（也就是台阶上去以后接平台的位置）。`height` 是总高度；`steps` 不写时按每级 0.15 米自动算。

### ramp 坡道

```json
{"type": "ramp", "name": "坡道", "from": [6.5, 2.0], "to": [6.5, 4.0], "width": 1.2, "z": 0, "z_to": 0.4}
```

### column / cylinder 柱子、圆柱体

```json
{"type": "column", "name": "柱子", "at": [[1.0, 4.5], [7.0, 4.5]], "radius": 0.25, "height": 3.2}
{"type": "column", "name": "方柱", "at": [3, 3], "size": [0.4, 0.4], "height": 3.0}
```

`at` 可以是一个点，也可以是多个点（一次建一排）。`cylinder` 写法相同，灰度按家具算。

### tree 树（室外遮挡用）

```json
{"type": "tree", "name": "槐树", "at": [[2, 10], [8, 11]], "height": 6.0, "canopy": 1.8}
```

## 建模原则

- 只要**体量和位置对**：墙、门窗洞、高差、柱子、大件家具。装饰、线脚、纹样、小摆件都不建。
- 人物会被挡住、要绕开、要坐或站上去的东西才建，比如桌椅床、屏风、台阶、栏杆。
- 室外场景用 `ground`（自动地面）+ 建筑体块 + 树。远处背景建个大概体块就够了。
- 平面图上看不出高度的，按下面的默认尺寸表填，并在空间尺寸清单里标"推测"。
