# 站位表 blocking.json

人物一律是**无四肢的彩色人偶**：头和身体分开，高 = 角色身高，肩宽约 0.44 米。坐、蹲、跪时变矮，躺下时横放（脸朝上）。不做手和脚。

人偶专门做成能看出朝向的样子：

- **身体**是角色的颜色，左右宽、前后扁 → 分得清正面和侧面
- **头**略往前探，**脸是浅色、后脑是深色** → 分得清正面和背面

为什么不用纯胶囊：胶囊转一圈都长一样，Seedance 只能从走路方向去猜人朝哪边，站着不动、原地转身时就容易画反。脸和后脑是真人本来就有的样子，不是额外加的道具，所以不会被画成多余的东西。

想对比旧效果，可以在 blocking.json 最外层写 `"figure": "capsule"`，全部人物换回纯胶囊；也可以只给某一个人物写。

坐标和角度规则同 [场景表](场景表.md#坐标约定三张表通用)：米；向右 +X，向上 +Y；朝向 0 = 朝上，90 = 朝右，顺时针。

## 结构

```json
{
  "duration": 12,
  "actors": [
    {"id": "A", "name": "帝江", "color": "蓝", "height": 1.78,
     "keys": [
       {"t": 0,   "pos": [2.0, 0.4], "face": 0},
       {"t": 4.0, "pos": [3.4, 2.9], "via": [[2.4, 1.8]], "depart": 0.5, "face": "B"},
       {"t": 12,  "pos": [3.4, 2.9]}
     ]},
    {"id": "B", "name": "帝鸿", "color": "红", "height": 1.75, "ignore": ["座椅"],
     "keys": [
       {"t": 0,   "pos": [4.0, 5.8], "pose": "sit", "seat_h": 0.45, "face": 180},
       {"t": 6.8, "pose": "stand", "dur": 0.8},
       {"t": 10,  "pos": [4.6, 3.2], "via": [[5.2, 5.8], [5.2, 4.7], [4.9, 3.9]], "depart": 7.0, "face": "A"}
     ]}
  ]
}
```

`duration` 只在还没有镜头表时用（`blocking` 阶段）；有镜头表时总长以最后一个镜头的结束时间为准。

最外层还可以写 `"figure"`：`"head"`（头身分开的人偶，默认）或 `"capsule"`（旧版纯胶囊）。

## 人物字段

| 字段 | 说明 |
|---|---|
| `id` | 简短代号，镜头表里用它引用人物（如 `"A"`）。不能重复 |
| `name` | 角色名，写进报告和交接卡 |
| `color` | `蓝 红 黄 绿 紫 橙 青 粉 白 黑 棕`，或 `#RRGGBB`。不写就按 蓝/红/黄/绿/紫/橙 依次分配。**同一场戏每个人颜色要分得开** |
| `height` | 身高（米），默认 1.75 |
| `radius` | 身体半宽（约等于肩宽的一半），默认 0.22。碰撞检查也按这个算 |
| `figure` | 只改这个人物的造型：`head` 人偶 / `capsule` 纯胶囊。不写就跟最外层的 `figure` |
| `hair` | 后脑的颜色，默认深棕黑。白发、光头的角色可以改浅一点；不改也行，成片的发色以提示词为准 |
| `ignore` | 允许接触的物体名，比如他坐的椅子、躺的床。碰撞检查会跳过它们 |
| `ghost` | `true` = 完全不做碰撞检查（比如穿过帘子） |
| `run` | `true` = 这个人在跑，速度检查放宽 |
| `keys` | 时间线，见下 |

## keys：时间线

每个 key 的意思是"**到 t 秒时，这个人是这个状态**"。没写的属性沿用上一个 key。第一个 key 必须写 `pos`，一般 `t` 为 0。

| 字段 | 说明 |
|---|---|
| `t` | 时间（秒），整片的绝对时间 |
| `pos` | 位置 [x, y]。高度不用写，会自动贴到脚下的地面、台阶、地台上 |
| `via` | 从上一个位置走到 `pos` 途经的点。拐角会自动倒成圆角 |
| `round` | 拐角圆角半径（米），默认 0.6；写 0 是直角拐弯 |
| `depart` | 几秒出发。不写的话，默认从上一个 key 的时间开始走，走满整段 |
| `speed` | 用走速（米/秒）倒推出发时间，和 `depart` 二选一 |
| `ease` | 起步和停步的缓冲。默认各约 0.5 秒；`"none"` 为匀速；`[0.3, 0.8]` 分别指定起步和停步 |
| `face` | 朝向：数字（罗盘角度）、另一个人的 `id`（持续朝向他，他走动时会跟着转）、或一个点 `[x, y]` |
| `face_lock` | `true` = 这段移动不自动转向行进方向（倒退、侧移时用） |
| `dur` / `turn_dur` / `pose_dur` | 转身或换姿态用多少秒（在 `t` 时完成）。转身默认 0.6，换姿态默认 0.8 |
| `pose` | 姿态：`stand` 站 / `sit` 坐 / `crouch` 蹲 / `kneel` 跪 / `lie` 躺（也可以写中文） |
| `seat_h` | 坐或躺时，座面/床面相对脚下地面的高度。坐默认 0.45，躺默认 0（躺地上） |

### 行为规则

- **走路**：位置变化的那个 key 定义一段移动，时间是 `depart`（或上一个 key 的时间）→ `t`。人会沿路线走，起步和停步有缓冲，身体朝向自动转向行进方向。
- **移动中途要停**：拆成两段，中间加一个"原地停留"的 key。
- **移动 + 换姿态在同一个 key**：先走到位，再用 `pose_dur` 的时间换姿态。比如走到椅子前坐下。
- **一直看着某人**：`"face": "B"`。B 走动时，A 会原地跟着转。
- **坐下**：位置写在座面中心，`seat_h` 写座面相对地面的高度，`ignore` 里写上这把椅子。
- **躺下**：位置是身体中心，`face` 是头朝的方向，`seat_h` 写床面高度。躺下后脸朝上（人偶会先转过身，再往后躺）。建议先坐再躺，否则会像一根柱子直挺挺地倒下。
- **上下台阶**：直接走过去就行，高度自动跟着变。

## 速度参考

| 动作 | 米/秒 |
|---|---|
| 踱步、慢走 | 0.6–0.9 |
| 正常走 | 1.2–1.4 |
| 快走 | 1.6–1.9 |
| 小跑 | 2.5–3.5（要写 `run: true`） |
| 跑 | 4–6（要写 `run: true`） |

超过 2.2 米/秒又没写 `run`，检查会报警告。

## 常用距离

| 关系 | 两人间距（身体中心之间） |
|---|---|
| 亲密、耳语 | 0.5–0.8 |
| 普通对话 | 1.0–1.5 |
| 正式、拘谨 | 1.5–2.5 |
| 对峙 | 2–4 |
| 上位者与下位者（殿堂） | 3–6 |

## 自动检查会查什么

- 走得太快或太慢
- 穿墙、穿家具（站立时检查；`ignore` 里的物体除外）
- 两个人身体重叠
