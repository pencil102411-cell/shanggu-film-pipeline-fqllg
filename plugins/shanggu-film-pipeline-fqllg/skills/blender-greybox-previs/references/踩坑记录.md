# 踩坑记录

使用中发现的新问题，按同样的格式追加在后面：现象 → 原因 → 怎么办。

## 环境

**`setup` 报找不到 Blender / FFmpeg**
→ 不在常见位置。用 `setup --blender <blender.exe 路径> --ffmpeg <路径> --ffprobe <路径>` 指定。

**提示缺少 Pillow**
→ 运行 `python -m pip install pillow`。

**Cycles 显卡渲染报 OptiX 错误**
→ 显卡驱动太旧。本工具只用 Workbench（Blender 自带的平涂渲染），不受影响。

**安装 MCP 时报"另一个程序正在使用此文件"（pywin32）**
→ 杀毒软件在扫描临时文件。改用独立的 Python 虚拟环境安装，见 [安装与MCP.md](安装与MCP.md)。

**PowerShell 5.1 写出的 JSON 开头带 BOM（一个隐藏的编码标记）**
→ 工具读取时会自动忽略，不用处理。

## 参数表

**人物"穿进座椅/床"**
→ 坐着或躺着的人本来就在椅子、床的范围内。在人物的 `ignore` 里写上这件家具的 `name`。

**门窗洞的 center 离墙太远**
→ `center` 要写在墙的中心线上（或者很接近）。中心线是 path 的折线，不是内墙面。

**镜头里写 hide 的物体名找不到**
→ 多段墙会被拆成"墙名_1、墙名_2……"（按 path 顺序，从 1 开始）。也可以用 `names` 给每段起名。

**人物走路提前好几米就开始拐弯**
→ 已修复：拐角改成固定半径（默认 0.6 米），可以用 `round` 调。

## Seedance 成片

**成片里人物朝向不对（背对镜头的人被画成正脸、对视的两人画成同一方向）**
→ 原因：旧版人物是纯胶囊，转一圈都长一样，Seedance 只能从走路方向去猜。已改成头身分开的人偶：脸浅色、后脑深色、身体前后扁。另外在提示词里写上"人偶头部浅色的一面是脸，人物面朝哪边以此为准"（交接卡里已自动生成）。想和旧效果对比，在 blocking.json 最外层写 `"figure": "capsule"`。

## 镜头

**画面一片灰 / 被墙挡住**
→ 相机在墙里，或在墙外面。自动剖墙（`auto_hide`，默认开）会隐藏挡路的墙、栏杆、天花。其他家具挡住时，在 `hide` 里写上名字，或者挪机位。

**21:9 室内全景装不下**
→ 21:9 画面很扁，竖直方向装下的东西少。换 18–24mm 广角，或让相机退到墙外（自动剖墙会处理）。

**跟拍人物拐弯时报"转得太快"**
→ 离得近，人一拐弯相机就得转很快。加大 `dist`；或者把人物这段路的 `round`（拐角半径）调大到 1–1.5 米；确实要这个效果就调高 `max_pan`。

**引路拍 / 跟拍时相机穿过人物**
→ 已修复：follow/lead 只沿人物当前这一段行走路线取位置。一个跟拍镜头里，人物最好只有一段连续行走。

**过肩镜头前景人物太大**
→ 加大 `back`（相机在前景人物身后的距离，默认 1.1），或换更长的焦段。

**"俯拍/仰拍"判断**
→ 按相机比主体眼睛高还是低来判断，不看镜头的低头角度。

## Blender 5.x 技术细节（改代码时注意）

- 用 Python 新建的形态键（shape key）强度默认不是 0，必须手动清零，否则几种姿态会叠在一起。
- Workbench 要开 `use_world_space_lighting`，否则灯光跟着相机转，运镜时明暗会变。
- 时间轴标记绑定了相机，渲染动画时会自动切相机；渲染单张图前要临时解绑（代码里已处理）。
- 动画全部逐帧写关键帧，不依赖 Blender 的曲线插值，所以每次生成结果完全一样。
- 时间和帧的换算：第 t 秒 = 第 t × 24 + 1 帧。例：5 秒处切镜 = 第 121 帧。
