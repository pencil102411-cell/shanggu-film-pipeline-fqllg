# 运镜与剪辑规则

目标：运镜自然、切镜流畅，Seedance 能看懂、能照着拍。下面是默认做法。用户的分镜有明确要求时，以用户为准；但违反规则可能出问题时，要提醒用户。

## 一、运镜要"像真机器拍的"

### 速度

| 运动 | 默认上限 / 常用范围 | 说明 |
|---|---|---|
| 摇（相机原地转） | ≤ 15°/秒，舒服的范围 5–10°/秒 | 24 帧下摇太快会有顿挫感。快摇、甩镜头要在镜头里写 `max_pan` |
| 推 / 拉 | 0.2–0.6 米/秒（情绪推进） | 越近、焦段越长，就要越慢 |
| 横移、跟拍 | 跟人物走速一致，0.8–1.5 米/秒 | |
| 升降（摇臂） | 0.3–0.8 米/秒 | |
| 环绕 | 每秒 10–20°，60° 以上记得调 `max_pan` | 绕人物比纯摇更能接受稍快的角速度 |
| 变焦 | 4 秒内焦距变化不超过 2 倍 | 按对数插值，速度均匀 |

一个参考：物体横穿整个画面，至少要 5–7 秒才不显得"跳"。

### 起停

- 所有运动默认缓入缓出：起动、停下各有缓冲，一般 0.5–1 秒。不要从静止直接匀速运动，也不要匀速中突然停住（除非是故意的急停）。
- 运镜中途要停：拆成两个 key。中途不该停：用 `via` 让相机连续经过几个点，不要连写多个 key（每个 key 都会停一下）。
- 跟拍时相机比人物晚 0.3–0.5 秒起步（默认 `lag` 0.35），不要像绑在人身上。

### 手持

- `handheld` 0.3：稳定器、轻微呼吸感；0.6：普通手持；1.0：紧张、慌乱。
- 手持适合情绪戏和近景；全景、建立镜头一般不手持。

## 二、机位、焦段、构图

### 默认机位

- **平视**：相机与人眼同高（默认值）。最中性，大部分镜头用它。
- **仰拍**（相机低于眼睛）：显得人物有力量、压迫。`h` 设为 0.5–1.0 米。
- **俯拍**（相机高于眼睛）：显得人物渺小、被审视，也用来交代空间。`h` 设为 2.5 米以上。

### 焦段选择（21:9、全画幅）

| 焦段 | 适合 |
|---|---|
| 16–24mm | 室内全景、建立空间、强烈的透视和纵深 |
| 28–35mm | 中性；跟拍、走动、中全景 |
| 40–50mm | 对话中景、过肩 |
| 65–85mm | 近景、特写，背景虚化压缩感 |
| 100–135mm | 远距离偷拍感、强烈压缩、窗外看室内 |

换焦段但想保持人物大小不变：新距离 = 旧距离 × 新焦段 ÷ 旧焦段。

### 构图

- 人物看向或走向画面的哪一边，那一边就多留空间：朝右看的人放在画面左三分之一（`frame: [0.38, …]`）。
- 眼睛大约放在画面高度的 60%–65%（中景及更近）。工具会按景别自动留头顶空间。
- 双人镜头用 `{"between": ["A", "B"]}`，景别会自动放宽到两人都装得下。

## 三、切镜要流畅

### 轴线（180 度规则）

两个对话或对峙的人之间有一条假想连线，叫"轴线"。**这场戏的所有相机都待在轴线同一侧**，否则切镜后两人在画面里会左右对调，观众会搞不清方位。

做法：先确定轴线和相机所在的那一侧，所有机位的 `az` 都选在这一侧。要越轴，中间加一个镜头沿轴线拍，或用运动镜头带过轴线。自动检查发现两人左右对调时，会报"越轴"。

### 30 度规则

同一个人连续两个镜头，机位角度至少差 30°，**或者**景别差两级（比如中景切特写）。否则看起来像画面跳了一下（跳切）。

### 动接动、静接静

- 运动镜头接运动镜头，固定镜头接固定镜头，最顺。
- 动作中间切（比如人物起身到一半时切），也很顺，这叫"动作剪辑点"。
- 静接动、动接静不是不能用，但要有理由（节奏变化、情绪转折）。检查报告会把这种情况列为"提示"。

### 走向一致

人物在上一个镜头里从左走向右，下一个镜头里也应该从左走向右（相机在轴线同侧时自然满足）。

### 镜头时长

| 镜头 | 常见时长 |
|---|---|
| 建立镜头、空镜 | 3–5 秒 |
| 对话单人 | 2–4 秒 |
| 动作、反应 | 1.5–3 秒 |
| 一镜到底 | 按动作走完的时间 |

短于 1.5 秒的镜头检查会提示。Seedance 也很难把太短的镜头拍清楚。

## 四、常见场面怎么拍

### 对话（两人）

1. 双人全景或中全景，交代两人位置和距离（轴线确定）。
2. 过 A 肩拍 B（`ots`，`side` 选轴线同侧）。
3. 过 B 肩拍 A（同侧）。
4. 情绪升级时换成单人近景，或者慢推。

### 人物走进场景

- 固定机位跟摇（世界式 + `look`），人物从远到近，交代空间。
- 或者引路拍（`lead`）拍正面，身后跟拍（`follow`）拍背影带出前方空间。

### 揭示空间

- 拉镜头从人物拉到全景，或者升镜头从低处升起俯瞰。
- 下摇：从建筑上方摇到人物（世界式，`look` 从高处的点换到人物）。

### 一镜到底

- 一个镜头里写多个 key，串起"跟 → 停 → 绕 → 推"。
- 每一段至少 1.5–2 秒，速度都在上限内。
- 不该停的地方用 `via`，不要连写多个 key。

## 五、Seedance 相关

- 太快的甩镜头、穿过物体的镜头，Seedance 不一定能复现，尽量避免。
- 参考视频里每个镜头都要看得清主体在哪；人物被挡住太久，Seedance 会丢失这个人物。
- 一条生成里切镜太多，Seedance 可能跟不住。镜头很多时，可以用 `final --per-shot` 分镜头导出，分开生成再剪辑。
