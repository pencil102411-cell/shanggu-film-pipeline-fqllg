# 镜头表 shots.json

一个镜头 = 一台相机。所有人物在一条连续的时间线上运动，多台相机按切点轮流"拍"，就像片场多机位同时开机。所以切镜前后人物的位置和动作天然连续。

坐标、角度规则同 [场景表](场景表.md#坐标约定三张表通用)。

## 结构

```json
{
  "resolution": [1470, 630],
  "defaults": {"lens": 35, "max_pan": 15, "handheld": 0, "auto_hide": true},
  "shots": [
    {"id": "镜01", "start": 0, "end": 4, "desc": "门口进入，固定机位跟摇",
     "keys": [{"t": 0, "pos": [7.3, 0.6, 1.65], "look": "A", "lens": 24}]},
    {"id": "镜02", "start": 4, "end": 7, "desc": "过帝江肩看帝鸿起身",
     "keys": [{"t": 4, "ots": {"over": "A", "to": "B", "side": "right"}, "lens": 40}]}
  ]
}
```

### 镜头字段

| 字段 | 说明 |
|---|---|
| `id` | 镜头名，如 `镜01` |
| `start` / `end` | 起止时间（秒）。第一个镜头从 0 开始，**镜头首尾相接**，不能有空档或重叠。会自动对齐到整帧 |
| `keys` | 机位关键点，见下。一个 key = 固定机位；多个 key = 运镜 |
| `desc` | 一句话说明，写进镜头参数表 |
| `lens` | 本镜头默认焦距（mm） |
| `handheld` | 手持晃动强度 0–1：0.3 轻微（稳定器感），0.6 普通手持，1.0 明显手持 |
| `max_pan` | 转动速度上限（度/秒），默认 15。快摇、甩镜头时调高 |
| `hide` | 本镜头里隐藏的物体名列表（比如挡镜头的墙、前景家具） |
| `auto_hide` | 自动剖墙，默认开：挡在相机和主体之间、或把相机包在里面的墙、栏杆、天花，只在本镜头隐藏 |
| `occlusion_ok` | `true` = 主体被前景挡住是故意的，不报警 |
| `subjects` | 主体人物 id 列表。不写就从 keys 里引用的人物自动推断。检查"出画/被挡"时用 |
| `lag` | 跟拍时相机晚多少秒跟上，默认 0.35 |
| `look_lag` | 镜头对准点的平滑，默认 0.2 秒 |

`resolution` 默认 [1470, 630]，即 21:9。`preview` 会自动用 700×300 出低清预览。

## 机位关键点 key：五种写法

每个 key 都有 `t`（整片的绝对时间，必须落在本镜头的起止时间内）。两个 key 之间的运动会自动缓入缓出。

### ① 环绕式：围绕目标定机位（最常用）

```json
{"t": 0, "target": "A", "size": "中景", "az": 200, "h": 1.6, "lens": 35}
```

| 字段 | 说明 |
|---|---|
| `target` | 围绕谁：人物 id、`{"between": ["A", "B"]}`（两人中点），或一个点 `[x, y, z]` |
| `size` 或 `dist` | 景别（自动换算距离）或水平距离（米） |
| `az` | 相机在目标的哪个方位（罗盘角）：180 = 相机在目标的下方（-Y 侧） |
| `az_rel` | 相对目标人物朝向的方位：0 = 正面，90 = 人物右侧，180 = 背后，-90 = 人物左侧，30 = 右前 3/4 侧 |
| `h` | 相机离目标脚下地面的高度。不写 = 与眼睛同高（平视） |
| `el` | 俯仰角（度）：正数 = 从上往下看，负数 = 从下往上看。和 `h` 二选一 |

**目标人物在走时，相机会跟着平移**（晚 `lag` 秒）。相机位置 = 目标位置 + 方位 × 距离，所以：

- `az` 固定 = 相机和人保持同样的相对方位，一起平移（横移跟拍、平行跟拍）
- `az_rel` = 跟着人物朝向转（人物转身时相机会慢慢绕过去）

### ② 世界式：相机放在固定位置

```json
{"t": 0, "pos": [7.3, 0.6, 1.65], "look": "A", "lens": 24}
{"t": 0, "pos": [7.5, 5.5, 2.4], "yaw": 225, "pitch": -15, "lens": 18}
```

| 字段 | 说明 |
|---|---|
| `pos` | 相机位置 [x, y, z]，z 是离地绝对高度 |
| `look` | 对准谁：人物 id（可加部位，如 `"A.body"`）、`{"between": [...]}`，或一个点 |
| `yaw` / `pitch` | 不写 `look` 时，直接给镜头朝向：`yaw` 用罗盘角（0 = 看向平面图上方，90 = 看向右，顺时针）；`pitch` 正值抬头、负值低头 |
| `via` | 从上一个 key 移动到这里途经的点 `[[x,y,z], ...]`，路线自动圆滑。适合摇臂、复杂轨道 |
| `round` | via 路线的拐角半径，默认 1.5 米 |

人物在走时，`look` 会让相机原地跟着摇。

### ③ 过肩式

```json
{"t": 4, "ots": {"over": "A", "to": "B", "side": "right", "back": 1.1, "offset": 0.45}, "lens": 40}
```

相机在 A 的肩后，看向 B。`side` 选 A 的哪一侧肩膀；`back` 是在 A 身后多远（默认 1.1）；`offset` 是往肩膀那侧偏多少（默认 0.45）；`h` 是相机离地高度（默认 A 眼高 + 0.08）。B 会被自动放在画面偏右（right）或偏左（left）三分之一处。

### ④ 身后跟拍 `follow`

```json
{"t": 16, "follow": "A", "dist": 2.8, "side": 0.4, "lens": 32}
```

相机沿 A **走过的路线**跟在身后 `dist` 米。人拐弯时，相机要走到拐角才会跟着转，和真实的跟拍摄影师一样。`side` 是向行进方向右侧偏移的距离（负数向左），偏一点能拍到 3/4 背影；`h` 是相机高度，默认人物眼高 + 0.05。

### ⑤ 前方引路拍 `lead`

```json
{"t": 12, "lead": "A", "dist": 2.5, "lens": 28}
```

相机沿 A **将要走的路线**，在前方 `dist` 米处倒退着拍他的正面。人停下时，相机停在他前方。

> follow 和 lead 只看人物当前这一段连续行走。如果镜头里人物停下后又换方向走，相机会重新找位置，会有一个过渡。最好让一个跟拍镜头只覆盖一段连续行走。

### 所有写法通用的字段

| 字段 | 说明 |
|---|---|
| `lens` | 焦距（mm），按全画幅 36mm 宽算 |
| `frame` | 对准点在画面中的位置 `[x, y]`，0–1，从左下角算。比如 `[0.33, 0.62]` = 左三分之一、眼睛在中上。不写会自动定：眼睛高度按景别留头顶空间，过肩镜头自动偏到一侧 |
| `roll` | 画面倾斜角度（度），即荷兰角 |
| `ease` | 从上一个 key 到这个 key 的缓冲：默认两端各约 0.35 × 时长（最多 1 秒）；`"none"` 匀速；`"in"` 只缓起；`"out"` 只缓停；`[0.5, 1.0]` 分别指定秒数 |
| `keep_size` | `true` = 希区柯克变焦：边推拉边反向变焦，主体大小不变，焦距自动算 |

### 对准部位

人物引用可以加部位：`A.eye`（眼睛，默认）、`A.head`、`A.body`（身体中部）、`A.top`（头顶）、`A.base`（脚底）。

### 两个 key 之间怎么插值

- 两个 key 都是环绕式、目标相同：插值"距离、方位角、高度"，所以**走的是圆弧**，环绕时不会抄近路。`az` 按数值插值：200 → 260 是顺时针，200 → 140 是逆时针，200 → 560 是顺时针转一整圈。
- 其他情况：按位置插值（直线，或者沿 `via` 路线）。
- 焦距按对数插值，变焦速度看起来更均匀。

## 景别 → 距离

写 `size` 时按"画面竖直方向要装下多高"换算距离，结果和焦距、画幅有关：

| 景别 | 画面竖直覆盖 | 21:9、35mm 时约多远 |
|---|---|---|
| 大特写 | 0.22 米（眼睛到嘴） | 0.5 米 |
| 特写 | 0.35 米（整张脸） | 0.8 米 |
| 近景 | 0.55 米（头肩） | 1.25 米 |
| 中近景 | 0.75 米（胸以上） | 1.7 米 |
| 中景 | 1.05 米（腰以上） | 2.4 米 |
| 中全景 | 1.45 米（膝盖以上） | 3.3 米 |
| 全景 | 2.3 米（全身留空） | 5.2 米 |
| 远景 | 5 米 | 11 米 |
| 大远景 | 12 米 | 27 米 |

**21:9 画面很扁**：同样的焦距，竖直方向装下的东西比 16:9 少。室内拍全景，往往需要 18–24mm 的广角，或者剖掉一面墙。

## 运镜词典（直接照抄改数字）

| 运镜 | 写法 |
|---|---|
| **固定** | 一个 key |
| **固定机位跟摇**（人走，相机原地转） | 一个世界式 key：`{"t":0, "pos":[…], "look":"A"}` |
| **推**（相机靠近） | 两个环绕式 key，目标和 `az` 相同，`size` 从大景别到小景别，或 `dist` 变小 |
| **拉**（相机后退） | 同上反过来 |
| **左/右摇**（相机不动，镜头转） | 两个世界式 key，`pos` 相同，`look` 从一处换到另一处 |
| **上/下摇** | 同上，`look` 的高度变化，例如从 `[x, y, 4.0]` 到 `"A"` |
| **横移**（相机平行移动） | 两个世界式 key，`pos` 横向平移，`look` 相同；或环绕式 `az` 固定，目标是正在走的人 |
| **跟拍（侧面平行）** | 一个环绕式 key：`{"target":"A", "az":180, "dist":3.5}`，A 走动时相机平行跟随 |
| **跟拍（身后）** | `{"follow":"A", "dist":2.8, "side":0.4}` |
| **引路拍（正面后退）** | `{"lead":"A", "dist":2.5}` |
| **升 / 降**（摇臂） | 两个环绕式 key，`h` 从 0.5 到 3.2；或世界式 `pos` 的 z 变化 |
| **环绕** | 两个环绕式 key，目标相同，`az` 从 150 到 210（60°）。60° 以上记得调高 `max_pan` |
| **变焦** | 两个 key，位置相同，`lens` 不同 |
| **希区柯克变焦** | `{"t":24, "target":"B", "dist":2.0, "az":180, "lens":24}` → `{"t":27, "target":"B", "dist":5.5, "az":180, "keep_size":true}` |
| **手持** | 镜头加 `"handheld": 0.6` |
| **过肩** | `{"ots": {"over":"A", "to":"B", "side":"right"}}` |
| **低角度仰拍** | 环绕式 `h: 0.5`，或 `el: -15` |
| **高角度俯拍** | 环绕式 `h: 3.0`，或 `el: 30` |
| **一镜到底** | 一个镜头里写多个 key，串起推、移、绕等动作；用 `via` 连续经过多个位置 |
| **双人镜头** | `"target": {"between": ["A","B"]}`，写了 `size` 会自动保证两人横向都装得下 |

## 自动检查会查什么

- 主体出画、主体被物体挡住（自动剖墙后仍被挡）
- 相机在墙或物体里面、相机低于地面、相机贴到人物身上
- 转动太快（超过 `max_pan`）、突然加速或急停
- 切镜：越轴（两人左右对调）、跳切（同一人角度差不到 30° 且景别差不多）、动接静/静接动
- 镜头短于 1.5 秒
