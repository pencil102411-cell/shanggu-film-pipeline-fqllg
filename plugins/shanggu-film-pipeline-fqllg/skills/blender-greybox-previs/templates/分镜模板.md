## 填写说明

- **时间**：镜头首尾相接，从 0 开始。
- **景别**：大特写 / 特写 / 近景 / 中近景 / 中景 / 中全景 / 全景 / 远景 / 大远景。
- **焦段**：不确定就留空，Agent 按规则选。
- **机位**：在谁的哪一侧（正面 / 侧面 / 背后 / 3/4 侧 / 过某人肩），高度（平视 / 低机位仰拍 / 高机位俯拍）。
- **运镜**：固定 / 推 / 拉 / 摇 / 横移 / 跟 / 升 / 降 / 环绕 / 变焦 / 手持 / 希区柯克变焦 / 一镜到底。
- **画面内容**：只写位置和走位，比如谁从哪走到哪、坐下、起身、转身面向谁。表情、手部动作、台词不用写，灰模表现不出来。
