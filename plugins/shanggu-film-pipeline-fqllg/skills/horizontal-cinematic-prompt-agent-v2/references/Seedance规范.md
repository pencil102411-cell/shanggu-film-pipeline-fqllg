- 素材引用统一写成 `(图片N)`、`(视频N)`，关键帧逐张写出，上玄上画布不用参考音频：`shared/素材引用写法.md`

用户提供的实际平台限制或已验证能力，优先于上述共用文件。

**拆条规则：** 按实际入口时长上限和用户要求安排生成条数；合并、拆条与切点的具体做法见 `AGENTS.md`「视频、镜头、时间段和节拍」。拆条时在代码块外写清拆点，连续各条沿用适用的资产、空间关系、光位和状态变化。

### 运镜与切镜设计

以下是可优先尝试的创作手法，**保留其叙事功能和画面力度，不将任何一项写成必定成功的能力承诺**：

| 类型 | 说明 |
|------|------|
| 复合运镜 | 可组合推/拉/摇/移/升降/环绕，如“拉+旋转+焦点转移”；写清同一摄影机的路径、速度与焦点交接 |
| 条内切镜 | 一条提示词可包含多个镜头；明确切点和承接状态，不把切镜误称为单镜内部无切点运动 |
| 长镜动作 | 单镜可设计连续多个攻防回合；交代双方目标、空间和受力因果，保留长镜的完整动作体验 |
| 大幅度运镜 | 如特写起幅→拉起上摇→鸟瞰全景→平移跟人；明确路径、视差与途中可见内容，检查机位是否能够连续到达 |
| 变速 | 可设计实速与慢动作的节奏转换，明确观众在慢下来的阶段需要看清什么 |
| 特效密度 | 可设计多发生点和多层粒子；按作用顺序、空间分层与主次关系描述，避免无因果的效果堆叠 |
| 短镜 | 1—2 秒镜头可用于清楚的单个信息或动作落点；它是视频条内的镜头时长，不等于单次生成时长 |

**调整依据：**

- 不凭“模型可能撑不住”等未经验证的泛化判断主动削弱镜头。先检查叙事、物理连续性和观看顺序；有实际失败画面、用户反馈或具体能力限制时，再针对根因优化，并说明对效果的影响
- 区分“拆镜”和“拆条”：拆镜改变剪辑，拆条改变生成任务。先采用能保留镜头意图的局部修改，再判断是否需要改变镜头或条数
- 当前入口没有可核实控制接口的帧率、升格倍率、分辨率等，不作为精确执行承诺写进提示词；改写为“能看清什么”的视觉结果。动作次数或转体角度确有叙事作用时可以保留，但要有清楚的起止姿态与落点，不用数字替代画面描述

## 二、提示词核心公式

```
【素材引用】+【风格】+【主体动作/状态】+【景别/精确焦距/景深】+【机位/运镜】+【光影动机】+【环境运动与反馈】+【稳定性约束】
```

**关键原则：有素材则引用，缺资料则区分已知与设计。** 已有角色/场景资产及环境信息时直接沿用，不重复索要；已看过的图用于身份、形制和空间参考，当前时间、天气、伤势及光照状态按本轮或已确认的要求（含场次记忆「连续性状态」）处理。时间轴补充动作、情绪、光线，不重复无用的五官、发型或建筑描述。用户要求先出时可用具名占位引用；未见图的灯具、窗位、服装细节不能写成已见事实，必要导演假设在代码块外说明。

## 三、时间轴组织

最终视频提示词用时间轴交代画面与状态变化。**一条视频**对应一次生成，可含多个镜头；**一个镜头**是切点之间连续的摄影机观察；**时间段**用于标记一个镜头或其中的状态变化；**节拍**是动作、信息或情绪的一次推进。一个镜头可以包含有因果的多个动作和节拍，不要求每拍另切一镜。时间戳只用整数秒，时间段首尾相接。

每个镜头交代适用的**景别/焦距/机距/透视/景深 + 机位/运镜或固定观察 + 可见画面 + 主体动作或状态 + 相关环境反馈**。普通镜头选一个精确焦距；明确镜内变焦时可写起止值及可见变化，详见 `references/镜头与灯光词典.md`。空镜描写景物和变化，不强加人物表演；室内静态环境或稳定光线可明确保持，不为填字段制造风、光动和粒子。

时长的取值顺序、估算方法和 15 秒兜底见 `AGENTS.md`「视频、镜头、时间段和节拍」。

### 15秒示例结构

```
0-3s  ：开场建立（景别 + 入画 + 环境初态）
3-8s  ：发展/爆发（主体动作展开 + 运镜推进 + 核心事件）
8-12s ：高潮/转折（画面重心变化 + 关键动作/反馈）
12-15s：收束/落版（余波 + 环境回落）
```

### 30秒结构

30秒视频可按 3—5 个阶段组织，每个阶段写清开始时、主要事件和结束时；时间戳只用整数秒，前一段结束时间与后一段开始时间相接。

```
0-5s：开始时建立空间；主要事件主体进入；结束时动作起点明确
5-12s：开始时承接动作起点；主要事件关系推进；结束时状态发生变化
12-22s：开始时承接状态变化；主要事件完成核心动作；结束时结果可见
22-30s：开始时承接结果；主要事件完成收束；结束时保持最终画面状态
```

> 这是时间组织示例片段，不是完整交付，也不是必须复制的四段模板。台词密度、动作节拍、情绪转折点决定实际切分；按估算时长或 15 秒处理时，也不必照抄这里的切点。

### 按镜头可见内容选择运动层

| 层级 | 内容 | 示例 |
|------|------|------|
| 主体运动 | 角色动作、表情变化 | 主角迈步前行、汗水滑落、瞳孔收缩 |
| 环境运动 | 天空、云、光影、风 | 云层缓慢飘动、树叶摇曳、光影移动 |
| 背景运动 | 人群、物体、粒子 | 人群快速移动、落叶飘散、尘埃飞扬 |
| 特效运动 | 火花、雨滴、烟雾 | 火花飞溅、雨水顺着屋檐滴落、烟雾扩散 |

上表是选项，不要求每段凑齐四层。室外风、雨、雪、雾或尘与镜头相关时，写清其本体变化和至少一项实际可见作用；画面同时容纳人物、场景、道具或光影的不同层时，可写两类反馈帮助建立受力因果。特写只写能看见的层，空镜不补人物，保持方向、湿度与累积状态连续。细则见 `references/室外环境动力.md`。

### 错误格式（禁止）

❌ 景别与构图互相矛盾、❌ 机位路径或切点不明、❌ 已写天气却没有任何可见作用、❌ 时间段衔接状态冲突。固定机位、稳定光线和无人物空镜本身不属于错误。

## 四、景别与运镜速查

### 景别

| 景别 | 画面范围 | 适用场景 |
|------|---------|---------|
| 远景 | 广阔空间，环境为主 | 开场建立场景、命运感 |
| 全景 | 人物全身 + 环境 | 展示人物与环境关系 |
| 中景 | 人物膝上 | 对话、双人动作 |
| 近景 | 人物胸上 | 表情变化、情绪传递 |
| 特写 | 面部/局部 | 关键情绪、证据、道具 |
| 主观视角 | 角色第一人称 | 沉浸感、紧张感 |

### 运镜/转场

| 方式 | 说明 | 情绪功能 |
|------|------|---------|
| 固定镜头 | 相机不动 | 压迫、观察、让表演发生 |
| 推镜头 | 相机向前 | 强调、心理压力增加 |
| 拉镜头 | 相机后撤 | 展示环境、孤立感 |
| 摇/移镜头 | 横向/纵向移动 | 展示空间、跟随 |
| 跟镜头 | 跟随主体移动 | 跟随运动、连续性 |
| 环绕 | 360度旋转 | 展示主体、被包围感 |
| 硬切 | 直接切换 | 节奏紧张 |
| 渐变 | 淡入淡出 | 情绪过渡 |
| 叠化 | 画面重叠 | 回忆、时间流逝 |
| 升格 | 慢动作 | 强调动作、情绪 |
| 降格 | 快动作 | 时间压缩 |

## 五、多模态引用语法

素材引用按以下顺序写；只有使用关键帧时才加第一行，并放在最前：

```
【素材引用】
以(图片X)、(图片Y)、(图片Z)的顺序作为关键帧
人物（按首次出场顺序；上传顺序与编号一致）：(图片1)、(图片2) 共同定义帝鸿（正面、侧面），成片中只有一个帝鸿；只取面部、发型和本场服装，不取图片背景
(音频1) 是帝鸿的音色；只取音色，不取原音频台词
(图片3) 是玲珑；只取面部、发型和本场服装，不取图片背景
其他主体：(图片4) 是玲珑的法相；只取形态与颜色
场景：(图片5) 是六象宫帝鸿书房正打方向；只取空间结构和陈设，不取图中人物和光线
道具：(图片6) 是黎奴骨鞭，归玲珑所有；只取形制、材质和尺寸
动作/运镜参考：(视频1) 只参考环绕运镜路径和节奏，不取人物外观、场景和光线
声音参考：(音频2) 只参考夜风环境声，不取音乐
```

> 上例只示范引用语法。排序、编号和每一行怎么写，以 `templates/标准输出模板.md`「素材引用」为准。关键帧逐张写出，不写「至」；要上玄上画布时不用 (音频N)（画布第一版不支持参考音频，音色和环境声改成文字描述），完整规则见 `shared/素材引用写法.md`。

## 六、稳定性约束词库

> **这是词库，不是必写清单。** 最终【保持一致】以 `templates/标准输出模板.md` 为起点，按用户要求和本镜实际设计判断适用性。特效戏的空间异变需要环境崩解，手持震动需要镜头抖动；删去或限定冲突的通用约束，保留其余必要的身份与连续性约束。

### 主体约束
`人物面部特征保持一致，不扭曲，不换脸，肢体比例自然`

### 场景约束
`没有剧情触发的场景结构与物件位置保持连续，环境变化按时间轴发生，不出现无因果的闪烁或突变`

### 动作约束
`动作起止、重心与接触因果清楚，不出现无意卡顿、穿插或反关节；动作幅度、瞬移或变形按本镜明确设计执行`

### 镜头约束

`镜头切换处角色形象、光位方向与色温、画面左右关系保持一致`

> 切点约束用于保持应连续的身份、光位与空间关系。不要把“平滑无抖动”作为所有镜头的默认口号；稳定推镜可要求平滑，手持震动则保留受控抖动。环绕、第一人称飞行、变速、跳切和构图改变是否适用，按各自镜头意图判断，不互相替代或一概排除。

### 光影色彩约束
`光源、阴影与曝光保持因果连续；固定光照段稳定，法术、遮挡、天气或人物移动引起的光变按时间轴发生`

### 音频约束
`不输出音乐、背景音乐、BGM、配乐、器乐、旋律或氛围铺底音；画面不带字幕；只保留台词、动作声和环境声。角色台词正常出声，可见口型与台词对齐。角色台词使用“角色台词（语气）：{台词原文}”，台词后不追加语气、表情或动作描述；画外音按实际声源写`

> 声音禁项写在哪个区块、写几次，以 `templates/标准输出模板.md` 为准。对口型是作品验收要求，不是模型必然成功的承诺。

## 七、文字分配与信息优先级

提示词写给 Seedance 2.5 视频模型，不是说明书也不是给人看的。每条文字最终输入模型时都必须有用。篇幅上限与统计口径见 `templates/标准输出模板.md`「篇幅」。

### 信息优先级

有人物承担叙事的镜头里，**主体行为包含动作与表演**。常见的写坏方式是把预算全花在景别和运镜上，人物只剩一句“她神情复杂地看着他”。应写可见行为，不用抽象标签代替表演；空镜、物件插入或看不见面部的镜头，不为完成表演字段增加不存在的人或微表情。

按“主体行为与表演 → 镜头关系 → 必要环境反馈”的顺序分配文字。主体必须写清，但不设固定字数占比；简单动作不为凑篇幅增加无意义微表情，复杂表演也不能被景别和运镜描述挤掉。

**表演层的写法要求**（细则与词库见 `modules/情感表演.md`）：

- **镜头中的叙事人物使用可执行表演**，不能只写“情绪化地”“神情复杂地”“眼神一冷”这类抽象标签；按可见景别选择视线落点、咬肌、呼吸、指尖或重心等适用表现，不要求每个部位同时变化
- **情绪必须有因果**：写清基线、触发和可持续终态；没有变化的克制表演可以保持稳定，不强行制造一次表情反转
- **配得上景别与对象**：人物近景/特写写镜头看得见的表演；手部、伤口、兵器等插入镜头写关键动作、材质或信息；远景大全景优先重心、步态、距离和群体关系
- **控制尺度和通道数量**：每个状态只保留一个主变化和至多一个辅助泄露；先确定泪态，删除互相冲突的表情与动作

**其余规则：**
- 提示词中的每段文字都必须是 Seedance 2.5 模型生成画面时需要的指令
- 不写背景说明、设计意图、创作思路、前情摘要等模型不需要的内容
- **技术参数要有实际依据**：默认把“2—4帧微定格”“120fps”“20—30倍升格”等改成可见停顿、运动速度和细节清晰度；只有用户所用入口确实支持对应控制时，才按其接口设置，不把提示词中的数字当作执行保证
- **动作先概括、重点写细**：动作先用概括句交代（例如“双方展开近身搏斗”），只把有记忆点的动作写细；不重复描写相同动作
- **有参考视频时不复述**：已用参考视频提供动作或运镜时，只写“(视频1)的动作”或“(视频1)的运镜”，不再逐步复述视频里的动作

## 八、提示词写作原则

| 原则 | 说明 |
|------|------|
| 目标导向 | 提示词是给模型的生产指令，不是设计说明。不写模型不需要知道的背景信息 |
| 素材引用优先 | 人物/场景/道具/运镜特征通过 (图片N)、(视频N) 等素材引用传递，不由文字重复描述 |
| 连续推进 | 一条视频可含多个镜头，一个镜头可含多个有因果的动作；按观众需要理解的节拍组织，不混写无关情节或前情总结 |
| 每个字必须有用 | 不写背景说明、设计意图、创作思路等模型不需要的内容 |
| 中文主干 | 主体描述一律中文；只有布光、运镜、材质、VFX 四类专业术语按「中文（English keyword）」附英文 |
| 只写可执行的 | 模型能生成画面的才写，帧率倍率之类的后期参数不写 |

---

> **最终视频提示词输出前，按 `templates/标准输出模板.md` 各节逐项核对**。只检查与当前镜头实际相关的项目，诊断、讨论和维护任务不套用最终提示词格式。
