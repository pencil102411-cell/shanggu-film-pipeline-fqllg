# video-local-edit

**已生成镜头局部修改**：为已有的视频镜头（尤其是 Seedance 生成的镜头）设计局部修改方案，并写出 Seedance 2.5 视频编辑提示词。

把待编辑的镜头当作唯一母版：只改变更单上的对象、区域、时段或声音类别，其余的表演、口型、机位、时间轴和音轨照原样继承。

## 与 video-rephotography 的分工

| | video-rephotography | video-local-edit |
| --- | --- | --- |
| 改什么 | 摄影层：机位、景别、运镜、切镜 | 内容层：对象、区域、光线、风格、声音 |
| 锁什么 | 表演、声音、视线、场景 | 表演、声音、视线、场景，**外加摄影层** |
| 时间 | 全片按源时间切换机位 | 全片或整数秒窗口内修改 |
| 提示词默认语言 | 英文 | 中文（与火山方舟官方编辑模板一致） |

两者共用同一套方法：母版、信息来源标注、源事件表、时间映射、成片验收。

## 能做什么

- 建立母版记录和编辑对象时间表，区分实测、用户提供、估计和未知。
- 把修改需求拆成变更单：对象、范围、A→B、参考素材只取哪部分、连带变化、解除的锁定和风险。
- 按类型给出提示词：删除并补全、替换主体或道具、背景替换、光线时段天气、时间窗事件、改表演、声音编辑，以及英文版。
- 新增类型模板：换角色造型（服装、发型、首饰）、换长相（换脸）、按镜头换背景内容。
- 复杂修改拆成多次编辑：不同镜头优先从原母版并行提交、在切点拼接；同一区域的叠加修改才链式编辑。
- 预处理参考图：去黑边、拆三视图、按机位裁背景（默认不缩小，照原图分辨率上传）。
- 依据实测记录先判断可行性；编辑失败后按“看片 → 找被误读的句子 → 从原母版重跑”的顺序诊断和修复。
- 给出提交参数、母版帧数处理（4 秒下限、8n+1 帧）、拼接与回贴命令、验收清单，以及原片与结果的上下对比视频脚本。

这是一套分析与提示词技能，不自带视频生成服务，也不会自动提交付费任务。

## 安装

本技能已并入「上古影视工作流-FQLLG」插件，装插件就带上了，安装方法见仓库根目录的 [README](../../../../README.md)。

插件形式下不要再把本文件夹复制到 `~/.claude/skills` 或 `~/.codex/skills`，否则会出现两份同名技能。

## 使用示例

```text
使用 video-local-edit 修改这段 Seedance 生成的镜头。
第 3-6 秒背景里多出一个路人，删掉；
女主手里的杯子换成图片1里的搪瓷杯，全片一致；
其他表演、口型、运镜和声音都不要动。
先给变更单，再给提交设置和提示词。
```

提供待编辑的视频文件（最好是剪辑前的原始生成文件），说明要改什么、改成什么；有参考图就一并给出，并说明它只用于哪一部分。

## 来源与验证边界

编辑能力、参数和已知问题来自火山方舟 Seedance 2.5 教程与提示词指南（核对于 2026-10-09），链接见插件根目录的 `shared/Seedance平台.md`。方法沿用 video-rephotography。

提示词自洽不代表成片一定按要求生效。只有实际生成并检查过的视频，才能报告成片验收结果。
