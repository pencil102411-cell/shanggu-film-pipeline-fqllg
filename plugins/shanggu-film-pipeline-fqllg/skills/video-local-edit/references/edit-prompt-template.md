# 编辑提示词模板

`{{...}}` 是编写时的变量，不是平台参数。按当前母版和变更单替换；没有来源的字段不能填假数。无参考素材、无声音变化、无时间窗时，删除对应区块。素材编号按上传顺序：`(视频1)`、`(图片1)`、`(音频1)`。

结构骨架来自火山方舟《Seedance 2.5 提示词撰写指南》2.4 节（编辑目标 / 原视频职责 / 目标素材职责 / 编辑范围 / 保持内容），本 skill 增加了“连带变化”“时间线继承”“禁止新增”三块。担心 `【】` 被误读为字幕时，可改用“编辑目标：”这样的写法。

## 通用模板

```text
【编辑目标】
编辑(视频1)，在{{全片 / 第a-b秒}}{{删除 / 替换 / 修改 / 增加}}{{对象、区域或声音类别}}：从{{A 的状态}}改成{{B 的状态}}。

【原视频职责】
(视频1)是唯一编辑母版，负责人物、动作、构图、机位与运镜、镜头切换、遮挡关系、光线、声音和事件顺序。

【目标素材职责】
(图片1)只用于{{目标对象}}的{{外观 / 结构 / 材质 / 颜色}}，不采用图片中的{{背景、人物、构图、光线}}。

【编辑范围】
只处理{{对象 / 区域 / 时间段 / 声音类别}}。全片{{目标对象}}始终只有{{数量}}个。{{第a-b秒以外不做任何修改。}}

【连带变化】
{{随编辑自然变化的阴影、反射、遮挡、环境光、手部接触、声音}}；除此之外，改动不扩散到其他区域。

【保持内容】
{{人物身份、五官、发型、服装、表情、口型、视线、动作路径与时点、手与道具的接触、位置与大小、机位、运镜、构图、镜头切换、光线方向、色调、对白和环境声}}保持(视频1)。

【时间线继承】
输出的每一时刻对应(视频1)的同一时刻，播放速度与原片一致；不加慢动作、不定格、不重复动作、不跳时。除以上明确修改的对象或区域外，(视频1)中的其他人物、道具、场景内容、镜头运动、镜头切换和事件顺序保持原样。

【禁止新增】
不新增人物、动作、台词、字幕、文字、水印或背景音乐。{{任务相关的排除项}}
```

## 按类型替换的区块

只列与通用模板不同的部分，其余区块照抄通用模板。

### 删除并补全

```text
【编辑目标】
编辑(视频1)，删除{{位置 + 识别特征，如：画面左后方穿灰色外套、背对镜头走过的路人}}。

【编辑范围】
只删除这个人物及其影子、倒影和脚步声。被遮挡的区域用(视频1)其他时刻可见的{{墙面 / 街道 / 桌面}}自然补全；没有出现过的区域延续相邻的材质和光线，不添加新的人物、物体或文字。
```

画面里乱码文字、错误招牌、多余手指，都可以按“删除 + 补全”来写。字幕单独做一次删除，不和其他编辑混在一起。

### 替换主体或道具（带参考图）

```text
【编辑目标】
编辑(视频1)，只把{{原对象，如：她右手拿着的白色陶瓷杯}}替换为(图片1)中的{{目标对象，如：深绿色搪瓷杯}}。

【目标素材职责】
(图片1)只用于{{目标对象}}的外观、结构和材质，不采用图片中的背景、手、构图或光线。

【编辑范围】
全片始终只有一个{{目标对象}}。只替换该对象；她的手指位置、握法、抬杯和放杯的时点保持(视频1)。

【连带变化】
杯身的高光、在桌面的投影和接触阴影随新材质自然变化。{{如材质不同：放杯时的碰撞声改为搪瓷的声音。}}
```

跨镜头统一角色或服装时，`(图片N)` 用项目里的角色设定图或服装参考图，并写明“只用于{{角色}}的{{服装 / 发型 / 配饰}}，不改变五官、表情和动作”。

### 换角色造型（服装、发型、首饰）

实测成功的写法。参考图各管一部分，造型逐项写出来，画面外的部件不强求出现。

```text
【编辑目标】
编辑(视频1)，全片替换{{角色识别特征，如：镜头一中正对镜头、镜头二中位于画面左侧的黑发女子}}的造型：发型和首饰改成(图片2)中的样子，服装改成(图片1)中的服装。{{其他角色识别特征}}不做任何修改。

【目标素材职责】
(图片2)只用于她的发型和首饰：{{按形状、颜色、材质逐项写：发髻形状、发带、发饰、耳坠、项链}}；不采用图片中的背景、光线、表情和头部角度。
(图片1)只用于她的服装：{{颜色、面料、领口、袖子、刺绣}}；不采用图片中的背景、站姿、构图和光线。

【编辑范围】
全片只处理这一名角色的头发、首饰和服装，全片始终只有她一人。原来的{{旧发饰、旧发型、旧服装}}全部去掉。画面里只露出{{领口、肩部、袖口}}，不为展示{{腰带、开衩、鞋子}}而改变构图。

【连带变化】
{{逆光下新发型和发饰边缘的轮廓光、薄纱的透光、耳坠和串珠随动作轻晃}}。除此之外，改动不扩散到其他区域。

【保持内容】
她的表情、视线、口型、动作时点和手的位置保持(视频1)。{{其他角色}}的服装保持原色，不受参考图颜色的影响。
```

- 造型按形状写，例如“头顶两侧用头发盘的尖角发髻”，不写“猫耳”这类会被当真的比喻；`【禁止新增】` 里补一句“不出现动物耳朵、角或其他非人特征”。
- 浓妆、红眼影容易被做成红眼睛，补一句“眼珠为自然的深棕色，不发光、不发红”。

### 换长相（换脸）

实测风险高：侧脸镜头能换成，正脸特写两次都保留了原来的长相。提交前先告诉用户，失败后考虑重新生成。

```text
【编辑目标】
编辑(视频1)，只替换{{角色}}的脸部长相：从{{A：如圆脸、圆而大的眼睛、柔和偏稚气的五官}}换成(图片1)和(图片2)中这个人的长相。这是换成另一个人的脸，不是只给原来的脸化妆：脸型、骨相、眉形、眼型、鼻梁和嘴唇形状都要换。

【原视频职责】
(视频1)是唯一编辑母版，负责她的表情动作（睁眼、闭眼、视线、嘴唇和头部的动作及时点）、发型服装，以及其他人物、构图、机位、镜头切换、光线和声音。(视频1)只提供她的动作，不提供她的长相。

【目标素材职责】
(图片1)是这个人的正脸，{{镜头一}}以它为准；(图片2)是同一个人的侧脸，{{镜头二}}以它为准。两张图只用于脸型和五官：{{B 的骨相逐项写：鹅蛋脸、尖下巴、略高的颧骨、细长平眉、细长上挑的眼型、高鼻梁、饱满的唇形}}。不采用图片中的头发、服装、背景、光线、表情和头部角度。

【编辑范围】
只处理她从发际线到下巴的脸部区域，两个镜头全程都换成这张脸。{{要保留的妆容、痣}}保留，落在新的五官上。

【保持内容】
她的表情动作和时点与(视频1)一致；保留的是动作，长相换成参考图中的人。{{其他人物和画面}}保持(视频1)。
```

- 不写“神情、表情与原片完全一致”或“神情保持原片”，这类话会把长相一起锁住。
- 每个角度用一张单独裁出的脸，让脸占满画面；朝向与镜头一致（侧脸方向相反就水平翻转）。
- 同时换造型时，把造型写法原样并进来，只把长相相关的几句换成本模板。

### 背景替换（换成参考图里的具体内容）

```text
【编辑目标】
编辑(视频1)，把{{镜头一 / 镜头二}}里人物身后的远景从{{原场景}}换成{{新场景}}：镜头一{{位置，如：男子身后}}换成(图片1)中的内容，镜头二{{位置，如：两人之间的远景}}换成(图片2)中的内容。这是替换背景里的具体物件，不是只把原场景改个颜色。

【目标素材职责】
(图片1)是镜头一{{位置}}要出现的{{物件逐项写}}。
(图片2)是镜头二{{位置}}要出现的{{物件逐项写}}。
两张图里的物件按图中的样子出现在背景里；不采用图片的构图和机位，按(视频1)各镜头的机位透视和景深重新摆放。

【编辑范围】
镜头一：删除{{旧元素逐项写}}，换成(图片1)的{{…}}。
镜头二：删除{{旧元素逐项写}}，换成(图片2)的{{…}}。原片最亮的位置保持明亮，作为人物逆光的来源。
{{前景锚点，如：两侧的前景书架}}保留原来的形状、位置和遮挡范围{{，只把颜色改成…}}。背景保持(视频1)原有的景深虚化；挂轴、招牌上的字只是虚化的墨迹，不出现清晰可辨的文字。

【连带变化】
只有人物头发边缘透出的背景随之变化，边缘自然，不出现白边或发丝缺失。

【保持内容】
人物是这次完全不动的部分：脸、五官、肤色、明暗、发型、服装颜色与质感、表情、口型、手势和动作时点，都与(视频1)逐帧一致，不随新背景改变人物的颜色和亮度。画面整体的亮度、对比度和色调保持(视频1)。机位、运镜、构图和镜头切换保持(视频1)。

【禁止新增】
不新增人物、动作、台词、字幕、文字、水印或背景音乐。人物前方不新增{{书案、茶桌}}或任何遮挡物。
```

- 参考图按每个镜头的机位裁出对应区域，去掉会被搬到人物前面的家具，避开大幅帘子、居中立柱这类强构图元素。
- 实测：只换人物身后一块、有前景框住的镜头能成功；背景占画面大半的双人中景被重新调度了机位，构图照搬了参考图。遇到后一种，把范围缩到“人物身后的一块”，保留原片已经合适的元素（窗、地板），或者按镜头拆开单独提交。

### 只改背景材质或色调

```text
编辑(视频1)，只把背景{{书架、墙面}}的颜色和材质从{{青绿色漆木}}改成(图片1)那样的{{深色实木}}；背景的布局、物件和位置都不变。人物的脸、肤色、明暗、服装和动作保持(视频1)。
```

参考图写成“只提供风格、材质、环境色”时，得到的就是这种效果。用户要的是换内容时，不要用这种写法。

### 光线、时段、天气

```text
【编辑目标】
编辑(视频1)，只把光线和时段从{{阴天正午的冷灰散射光}}改成{{傍晚低角度的暖橙色斜射光}}。

【连带变化】
人物肤色、物体投影的长度和方向、窗户反光随新光线自然变化。

【保持内容】
人物、服装、道具、位置、动作、表情、口型、构图、机位和运镜保持(视频1)。
```

光线描述两端都要写（从什么光改成什么光），不要只写“更暖一点”。

### 时间窗事件或特效

```text
【编辑目标】
编辑(视频1)，在第{{a-b}}秒增加{{事件，如：窗外一道闪电照亮室内}}。

【编辑范围】
{{事件}}从第{{a}}秒开始、第{{b}}秒前结束，{{出现与消失的方式}}。第{{a}}秒之前和第{{b}}秒之后的画面与声音保持(视频1)，不做任何修改。

【连带变化】
闪光期间，人物面部和墙面短暂被照亮；{{如需声音：<远处雷声>在闪光后约一秒出现。}}
```

### 改表演（解除锁定）

```text
【编辑目标】
编辑(视频1)，只把第{{a-b}}秒{{人物}}的动作从{{原动作}}改成{{新动作}}。

【解除的锁定】
仅在第{{a-b}}秒解除{{人物}}的{{手部动作 / 表情 / 视线}}锁定；第{{a}}秒的起始姿态和第{{b}}秒的结束姿态与(视频1)衔接。

【保持内容】
第{{a-b}}秒以外的全部表演，以及全片的身份、服装、场景、机位、运镜、对白和环境声保持(视频1)。
```

### 声音编辑

```text
编辑(视频1)，只去掉背景音乐：删除所有音乐、背景音乐、BGM、配乐、器乐、旋律和氛围铺底音，保留人物对白、口型、环境声和动作音效；画面内容、镜头和剪辑节奏保持(视频1)。音频只保留对白、环境声和动作音效，不产出任何音乐类音轨。
```

```text
编辑(视频1)，只修改第{{a-b}}秒穿深色西装男子的台词：
男子台词（压低声音）：{先别告诉她。}
说话时点、音色和语速与原台词一致，口型随新台词精准对位。其他人物的声音、环境声和画面保持(视频1)。不要字幕。
```

人物、情绪和台词按实际替换；台词本身放在 `{}` 里。

翻译时按角色给出完整目标语言台词和时间轴，要求所有角色（包括背景里可辨认的低语和语气词）都改成目标语言，全片不残留原语言。

## 多次编辑（pass）写法

每次提交只做一类变更。

### 并行（优先）

不同镜头或时间窗各改各的，都用同一个原母版，最后在切点拼接。不会一轮轮损失画质，某一条失败也只需重跑那一条。

```text
A · 母版：{{原文件}}_8n+1.mov · 只改镜头一 · 提示词：……（镜头二写“全部画面与声音保持(视频1)，不做任何修改”）
B · 母版：同一个文件 · 只改镜头二 · 提示词：……（镜头一同样写保持不变）
拼接：A 取切点前，B 取切点后；各自实测切点，音轨用母版原音。
```

也可以先把两处修改合成一条试，省一次生成。合并版要逐镜头写清“只改谁”，并把另一个人的相关状态写成保持项，例如“镜头二中女子始终闭着眼”。没成功的镜头，再用单镜头版从原母版重跑并拼接。

### 链式（同一区域要叠加多类修改时）

```text
第 1 次 · 母版：{{原文件}}.mov · 目的：删除背景路人 · 提示词：……
第 2 次 · 母版：第 1 次输出.mov · 目的：光线改为傍晚 · 提示词：……
第 3 次 · 母版：第 2 次输出.mov · 目的：去背景音乐 · 提示词：……
```

每次的“保持内容”都指向当次母版。上一次的改动在下一次中属于保持项，要写进去，例如“已删除的路人保持不出现”。链式每一轮都会重画整帧，画质逐轮下降，开始前要告诉用户。用户不接受时，改成从原母版一次写全，或者按镜头并行。

## 英文模板

英文入口（Runware、BytePlus、Scenario 等）以编辑动词开头，引用标签按当前入口写法，常见为 `@Video1`、`@Image1`。

```text
Edit @Video1: {{remove / replace / relight / restyle / change}} {{object, region or sound class}} {{in the whole clip / between 0:0a and 0:0b}}, from {{A}} to {{B}}.
@Video1 is the only edit master and defines the people, actions, framing, camera position and movement, cuts, occlusion, lighting, sound and event order.
{{@Image1 provides only the appearance, structure and material of {{target}}; do not use its background, people, framing or lighting.}}
Change only {{object / region / time window / sound class}}. There is exactly {{N}} {{target}} throughout the clip.
Let {{shadows, reflections, contact, ambient light, sound}} adapt naturally to the change; nothing else changes.
Keep identity, faces, hair, wardrobe, expressions, lip movement, eyeline, action paths and timing, hand-object contact, positions, camera position and movement, framing, cuts, light direction, colour grade, dialogue and ambience exactly as in @Video1.
Every output moment shows the same moment of @Video1 at the same speed: no slow motion, freeze frames, repeated actions or time skips. Everything not named above stays unchanged.
No added people, actions, dialogue, captions, text, watermarks or music.
```

## 信息不足时

- 不知道编辑对象在哪些时段出现：可以写全片编辑，并把“对象时间表”列为待核对；不编造时点。
- 只有截图：能写对象识别特征和目标外观，不能判断遮挡、手持阶段和口型，相关项标“未核对”。
- 用户只给出口头描述（“把那个杯子换掉”）：先确认具体是哪一个对象、全片有几个；画面里有多个相似对象时，必须用位置、颜色、所属人物来区分。
- 母版需要补手柄或裁剪：重新计算时间窗，改写“编辑范围”里的秒数，不能沿用旧时间。
